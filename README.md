# dwell-site

Static site for [Dwell](https://github.com/Shreyaanp/maps), the geofence-timer
app for Android + Wear OS. Hosted on Vercel at https://dwell.shreyaan.work.

- `/` — landing page
- `/privacy` — privacy policy (linked from the Google Play listing)

No build step; plain HTML served statically. `vercel.json` enables clean URLs
(`/privacy` instead of `/privacy.html`).
